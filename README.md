# Danilo Luz Jr. — Professional Portfolio

Modern interactive portfolio showcasing multi-disciplinary expertise across **HealthTech & Software Engineering**, **Clinical & Surgical Healthcare**, and **Academic Biomechanics & Higher Education**.

🌐 **Live Website:** [https://dans-portifolio.vercel.app/](https://dans-portifolio.vercel.app/)

## Features
- **Interactive Career Timeline Matrix**: Vector SVG-based timeline (2005–2027+) with live milestone inspector, non-overlapping labels, and category filtering (Healthcare, Education, IT).
- **Editorial Subpages**: Detailed journeys in Systems Analysis, Nursing, and Education with responsive newspaper-style image wrapping.
- **Modern Glassmorphism Design**: Frosted glass transparency, dark ambient background, and high-contrast accessibility.
- **Fast & Responsive**: Pure semantic HTML5, CSS3, and vanilla JavaScript without heavy external libraries.
